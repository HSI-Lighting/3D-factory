Bundled fonts used by the cad_text TTF engine.

DejaVuSans.ttf
    - The DejaVu fonts project (https://dejavu-fonts.github.io/).
    - Covers Latin, Greek, Cyrillic, Arabic, Hebrew and more — used as the
      script fallback so RTL (Arabic/Hebrew) text always shapes, regardless
      of which fonts are installed on the system.
    - License: Bitstream Vera license + public domain additions. Redistribution
      and modification permitted, with the copyright notice preserved
      (see https://dejavu-fonts.github.io/License.html).

LiberationSans-Regular.ttf
    - The Liberation fonts project (https://github.com/liberationfonts),
      metric-compatible with Arial.
    - Used as the guaranteed default font so the engine is always ready,
      even on systems with no installed fonts.
    - License: SIL Open Font License 1.1 (https://openfontlicense.org/).
